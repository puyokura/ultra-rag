ultra-RAG

dshのための、自分のPCで動く記憶とキー保管庫。知識を蓄え、必要なときだけ取り出し、秘密値は選択した子プロセスだけに渡します。

サーバーは必須ではありません。 公開版の基本構成はPC単体で完結します。データはローカルのアプリケーションデータ領域に保存され、ホームサーバー同期は任意です。

できること

知識の記憶

原則・教訓・判断基準を保存。READMEや設計文書のコピーは保存しません。

スコープ分離

全案件共通、プロジェクト固有、セッション限定を分けて扱います。

暗号化キー保管庫

AES-GCM。WindowsはDPAPI、Linuxはsystemd-credsで保護します。

MCP / dsh連携

stdioのMCPサーバーとCordisプラグインで、記憶を文脈へ注入します。

インストール

git clone https://github.com/puyokura/ultra-rag.git
cd ultra-rag
python -m venv .venv
.venv\Scripts\activate   # Windows
pip install -e .
ultra-rag init

使い方

ultra-rag rag remember "実プロセスで検証する" --kind lesson --scope shared_lesson
ultra-rag rag search "検証"
ultra-rag secret add EXAMPLE_API_KEY --service example
ultra-rag secret list
ultra-rag secret exec --key <KEY_ID> --command "python -c \"import os; print(bool(os.environ.get('EXAMPLE_API_KEY')))\""

設計上の約束

  • 秘密値は一覧・監査・モデルへ返さない。
  • 値を渡したコマンドは値を読める。マスキングは誤出力の低減であり、外部送信を防がない。
  • HTTP APIはプライベートネットワークかTLSリバースプロキシの内側で使う。
  • 文書の内容ではなく、再利用できる知識だけを記憶する。
